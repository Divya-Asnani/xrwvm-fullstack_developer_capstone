# IBM Full Stack Software Developer Capstone Project

**Repository Name:** `xrwvm-fullstack_developer_capstone`  
**Project Name:** Dealership Review and Management Application ("Best Cars Dealership")

---

## Overview

This repository contains the capstone project for the **IBM Full Stack Cloud Developer** certification program. The application is a national dealership review and vehicle browsing platform built with a Django backend and a React frontend.

---

## Tech Stack

- **Backend:** Python, Django
- **Frontend:** React, HTML5, CSS3, Bootstrap
- **Database:** SQLite (development)
- **Deployment & Architecture:** Microservices, Docker, Cloud Foundry/Code Engine (future modules)
